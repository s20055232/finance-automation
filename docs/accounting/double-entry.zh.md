# 複式記帳

每一筆財務交易都要**記兩次** — 一次借方、一次貸方。
這是現代會計的基礎，起源於 15 世紀的義大利。

## 黃金法則

```
總借方 = 總貸方 = 0
```

想像一個天秤：每次錢移動，兩邊都必須保持平衡。

## 這個系統如何應用複式記帳

當 AI 把一張發票分類為**設備採購**時，自動產生：

```
借：電腦設備（Equipment）  $4,097.98   ← 資產增加（公司多了一台筆電）
貸：現金（Cash）           $4,097.98   ← 資產減少（付出去了）
```

分類為**專業服務**時：

```
借：專業服務費（Professional Services）  $1,270.00  ← 費用發生
貸：應付帳款（Accounts Payable）         $1,270.00  ← 負債（還沒付款）
```

系統驗證每一張發票：若 `總借 ≠ 總貸`，立即標記為 **CRITICAL 異常**並發送 Email 警報。

## 五大帳戶類型

| 類型 | 正常餘額 | 增加方向 | 範例 |
|------|---------|---------|------|
| **資產（Asset）** | 借方 | 借 | 現金、設備、應收帳款 |
| **負債（Liability）** | 貸方 | 貸 | 應付帳款、借款 |
| **權益（Equity）** | 貸方 | 貸 | 股本、保留盈餘 |
| **收入（Revenue）** | 貸方 | 貸 | 銷售收入、服務費 |
| **費用（Expense）** | 借方 | 借 | 租金、薪資、廣告費 |

!!! tip "記憶技巧"
    費用、資產 → 借方增加；負債、收入、權益 → 貸方增加。
    簡單記：「費資借增，負收權貸增」。
